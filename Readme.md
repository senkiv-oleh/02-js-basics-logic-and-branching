# **Інструкція з виконання завдань  з JavaScript**

 У цій інструкції розписано всі кроки, необхідні для налаштування середовища, створення власної копії проєкту, виконання завдань та відправки коду на перевірку.

## **Крок 0. Підготовка робочого середовища**

Перед тим як відкривати посилання на завдання, переконайтеся, що на вашому комп'ютері встановлено необхідні інструменти:

1. **Node.js** (середовище виконання JavaScript та запуск автотестів)

   * *Перевірка:* відкрийте термінал і введіть `node -v`. Якщо відображається версія (наприклад, `v18.x.x` або `v20.x.x`) — все налаштовано.

   * Якщо програма відсутня, завантажте версію **LTS** з офіційного сайту [nodejs.org](https://nodejs.org/).

2. **Git** (система контролю версій)

   * *Перевірка:* введіть у терміналі `git --version`.

3. **VS Code** (або інший редактор коду).

4. **Акаунт на GitHub** (зареєструйтеся на [github.com](https://github.com/), якщо у вас ще немає акаунту).

## **Крок 1. Створення власної копії (Fork)**

Коли ви відкриваєте посилання на мій репозиторій викладача, ви не можете редагувати код безпосередньо в ньому. Для цього потрібно створити власну копію.

1. Перейдіть за посиланням на завдання

2. У правому верхньому куті сторінки знайдіть і натисніть кнопку **Fork**.

3. На сторінці, що відкриється, натисніть **Create fork**.

> **Результат:** На GitHub буде створено точну копію проєкту у вашому особистому акаунті (`github.com/ВАШ_USERNAME/НАЗВА_РЕПОЗИТОРІЮ`).

## **Крок 2. Клонування проєкту на комп'ютер (Clone)**

1. Переконайтеся, що ви перебуваєте на сторінці **свого** форкнутого репозиторію.

2. Натисніть зелену кнопку **Code** та скопіюйте HTTPS-посилання.

3. Відкрийте **VS Code** і викличте термінал за допомогою комбінації `Ctrl + ~` (або через меню `View -> Terminal`).

4. Виконайте команди для клонування та переходу у папку проєкту:

```
git clone <скопійоване_посилання>
cd <назва_проєкту>
```

5. Відкрийте цю папку у VS Code: `File -> Open Folder` -> оберіть папку `<назва_проєкту>`.

## **Крок 3. Встановлення залежностей**

У проєкті налаштовано автоматичні тести на базі фреймворку **Jest**. Щоб завантажити необхідні для їхньої роботи бібліотеки, виконайте у терміналі VS Code команду:

```
npm install
```

*(Зачекайте декілька секунд до завершення завантаження).*

## **Крок 4. Написання коду та перевірка**

1. У лівій панелі файлів відкрийте файл **`src/script.js`**.

2. Знайдіть функції з коментарями `// TODO: Implement function`.

3. Напишіть реалізацію для кожної функції.

4. Для перевірки виконання функцій запустіть у терміналі команду:

```
npm test
```

* **Зелений колір (Passed):** Тест пройдено успішно.

* **Червоний колір (Failed):** У коді є помилка. Прочитайте повідомлення в терміналі — воно підкаже, яке значення очікувалося і що повернула ваша функція.

## **Усунення можливих проблем (Troubleshooting)**

Якщо при виконанні `npm test` у Windows (PowerShell) виникає помилка видавництва:

> *"cannot be loaded because running scripts is disabled on this system"*

**Вирішення:**

1. Виконайте у терміналі PowerShell команду:

   ```
   Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process
   ```

2. Або переключіть тип термінала у VS Code з **PowerShell** на **Git Bash** чи **Command Prompt (CMD)**.

## **Крок 5. Здача роботи (Pull Request)**

Коли всі тести виконуються успішно, відправте роботу на перевірку:

1. Збережіть зміни у файлах (`Ctrl + S`) та виконайте в терміналі наступні команди:

```
git add .
git commit -m "feat: completed all 15 tasks"
git push origin main
```

2. Відкрийте браузер і перейдіть на сторінку **оригінального репозиторію викладача** (`github.com/senkiv-oleh/03-js-basics-loops`).

3. Перейдіть у вкладку **Pull requests** та натисніть **New pull request**.

4. Натисніть **compare across forks**, у полі **head repository** виберіть ваш репозиторій та натисніть **Create pull request**.

5. Натисніть **Create pull request** для підтвердження.

6. Прикріпіть посилання на **Pull requests** в СДО.
